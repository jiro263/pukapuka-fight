# ぷかぷかファイト　最善手探索

スマートフォン・タブレット・PCのブラウザで使える静的Webアプリです。

## GitHub Pages の有効化

1. このリポジトリの **Settings → Pages** を開きます。
2. **Build and deployment → Source** で **Deploy from a branch** を選びます。
3. Branch を **main**、Folder を **/(root)** に設定して **Save** を押します。
4. Pages の画面に表示される URL からアクセスできます。

公開URLの形式: https://jiro263.github.io/pukapuka-fight/

このアプリは `index.html` 1ファイルにCSS・JavaScript・駒画像を内包しています。追加のビルドやサーバーは不要です。
